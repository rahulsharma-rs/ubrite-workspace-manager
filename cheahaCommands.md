## Load Anaconda Environment
```module load Anaconda3```
## create a new conda environment
```conda create --prefix /data/user/$USER/ondemand/dev/rc_workspace/venv python=3.11```
## Activate the conda environment
```conda activate /data/user/$USER/ondemand/dev/rc_workspace/venv```

## Install required packages
```pip install -r /data/user/$USER/ondemand/dev/rc_workspace/ubrite-workspace-manager/requirements.txt```
