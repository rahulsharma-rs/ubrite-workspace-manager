Creating a GitLab Personal Access Token
Steps to create a Personal Access Token:
  1. Go to your GitLab instance (e.g., https://gitlab.rc.uab.edu)
  2. Click on your avatar in the top-right corner
  3. Select Edit Profile
  4. In the left sidebar, click Access Tokens
  5. Click Add new token
  6. Fill in the form:
    • Token name: UBRITE Workspace Manager
    • Expiration date: Set a future date (recommended: 1 year)
    • Scopes: Select api (required for repository management)
  7. Click Create personal access token
  8. Copy the token immediately (you won't be able to see it again)
  9. Paste the token in the field above and click Validate
Required Scopes:
  • api - Full API access (required for creating and managing repositories)
Security Notes:
  • Keep your token secure and don't share it
  • Set an expiration date for security
  • You'll be notified when the token is about to expire
  • The token is encrypted before being stored
