Creating a GitLab Personal Access Token
  1. Go to your GitLab instance: https://gitlab.rc.uab.edu
  2. Click on your avatar in the top-right corner
  3. Select Edit Profile
  4. In the left sidebar, click Access Tokens
  5. Click Add new token
  6. Fill in the form:
    • Token name: UBRITE Workspace Manager
    • Expiration date: Set a future date (optional but recommended)
    • Scopes: Select api (required for full API access)
  7. Click Create personal access token
  8. Copy the token immediately (you won't be able to see it again)
  9. Paste the token in the form above
Important: Keep your token secure and don't share it with others. The token provides access to your GitLab account.
