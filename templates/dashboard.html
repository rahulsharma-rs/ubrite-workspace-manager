Creating a GitLab Personal Access Token
  1. Go to GitLab Personal Access Tokens
  2. Click "Add new token"
  3. Enter a name like UBRITE Workspace Manager
  4. Set an expiration date (recommended: 1 year)
  5. Select the "api" scope
  6. Click "Create personal access token"
  7. Copy the token and paste it in the form above
Important: The token will only be shown once. Make sure to copy it immediately.
